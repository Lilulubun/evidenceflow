# Caldera / EVIDENCEFLOW

User-authored direction, transcribed for this refinement.

## Identity
Warm volcanic industrial/editorial light application. Real evidence workflow, not a marketing page. Graph is primary content; inspector exposes original provenance. Synthetic/local, not-live-Hindsight and demo authentication limits stay visible.

## Palette
- Pumice `#e2e2df`: page canvas.
- Limestone `#f7f6f2`: flat surfaces.
- Obsidian `#070607`: all primary text.
- Ember `#fc5000`: primary action, selected evidence. Obsidian text, not white.
- Sulfur `#f5f28e`: functional status tags only.
- Plasma `#524ae9`: only one compact signature halftone surface per page, never controls or graph node colors.
- No other accent hues. Errors use explicit text and border, never color alone. Zero shadows.

## Typography
- Requested display: PP Neue Corp Compact. Proprietary font unavailable; implementation uses openly licensed Anton, an honest condensed display substitute, never claims to include PP.
- Display headings: condensed structural 48–96px fluid, positive tracking .02em, line-height .94–1.1. Small display headings at least 26px. 189px maximum only if useful, not required in application.
- Body, navigation and buttons: DM Sans 500 only, 14/16/18px, line-height 1.2–1.55. Support headings may reach 30px.
- Captions/meta: 12px system sans 400.
- Self-host WOFF2, retain system fallback and license attribution. No runtime font network dependency.

## Layout and components
- Content max-width 1280px. Element gap 16px. Section gap 80px only where content fits; avoid empty workflow screens.
- Cards radius 40px, desktop padding 40px; deliberate reduced mobile spacing.
- Inputs radius 100px. Buttons radius 800px or 40px, primary padding 12px 24px.
- Thin Obsidian dotted dividers separate meaningful groups. Flat surface hierarchy, no shadows.
- Tables wrap long IDs and remain readable; contained scrolling permitted when needed.
- Graph uses monochrome shapes and a text legend, Ember selection and functional Sulfur. Links represent stored provenance only, no inferred semantics. Responsive stacked inspector and accessible node list remain available.

## Design read
Evidence workspace for employees, managers and HR, warm volcanic industrial/editorial language.
ENERGY 3 / RHYTHM 2 / MOTION 1: bold condensed structural headings, graph/inspector composition and compact workflow forms, hover/focus feedback only.

Fixed light palette follows explicit user branding, not an omitted theme toggle. Card surfaces are rounded rectangles, controls pills, tags square-edged, graph types distinct shapes: radius variation remains structural.
